# Новый кампус МГТУ «СТАНКИН»

Сайт о новом кампусе МГТУ «СТАНКИН» в Коммунарке: учебный комплекс из семи корпусов, Головной центр компетенций (ГЦК), общежития, спортивный центр, общественные пространства и ход строительства.

**Адрес:** https://peretyaginmstu-jpg.github.io/stankin-campus/

> Это предварительная версия для согласования, доступ по приглашению. Содержимое страниц зашифровано и открывается только после входа по логину и паролю. Поисковым системам индексация запрещена (`robots.txt`, `noindex`).

## Как устроена защита

Сайт статический и размещается на GitHub Pages, поэтому доступ ограничен шифрованием на стороне браузера, а не сервером.

1. Каждая HTML-страница содержит только экран входа и зашифрованный блок `<script id="gate-data">` с самой страницей.
2. Из логина (без учёта регистра) и пароля через PBKDF2-SHA-256 (250 000 итераций, общая соль) получается ключ AES-GCM-256.
3. Этим ключом браузер расшифровывает страницу и показывает её. Если логин или пароль неверны, расшифровка не проходит.
4. Ключ сохраняется в `localStorage` (`gate.key`) на 7 дней, чтобы не вводить пароль на каждой странице. Если соль сменилась (сайт перешифрован с новыми данными для входа), сохранённый ключ перестаёт действовать.
5. Данные каталога объектов (`campus-data*.enc.json`) зашифрованы тем же ключом и расшифровываются в `app.js`.

Для работы нужен JavaScript и браузер с поддержкой Web Crypto API (любой современный браузер; сайт должен открываться по HTTPS).

## Структура репозитория

В репозитории лежит **готовая сборка** сайта: файлы публикуются как есть, без шага сборки на стороне GitHub.

```
index.html, 404.html          главная и страница «не найдено» (ru)
campus/ science/ life/        разделы на русском
partners/ project/ sources/
en/ zh/                       те же страницы на английском и китайском
campus-data*.enc.json         зашифрованные данные каталога объектов (ru / en / zh)

styles.css                    базовые стили и шрифты
ui.css, ui.js                 общий слой: шапка, появление блоков, счётчики, анимации
home.css                      стили главной страницы
interior.css                  стили внутренних страниц
a11y.css, a11y.js             версия для слабовидящих
app.js                        меню, просмотр изображений, каталог объектов, фильтры хроники
i18n.js                       подписи интерфейса на трёх языках

assets/                       изображения (webp, варианты -900 и -1600), видео, логотипы
assets/fonts/                 шрифты Golos Text и Prata (woff2 по наборам символов)
assets/icons/                 иконки Lucide
.nojekyll                     отключает обработку Jekyll на GitHub Pages
```

Исходники страниц и скрипты сборки (`scripts/build.py`, `scripts/validate.py`), которые упоминаются в комментариях к коду, в этом репозитории не хранятся. Правки текста и содержимого страниц нужно делать в исходниках, заново собирать и шифровать сайт, а затем публиковать результат сюда. HTML-файлы в этом репозитории вручную не редактируются: их содержимое зашифровано.

Все пути в HTML начинаются с `/stankin-campus/`. Скрипты вычисляют адреса ресурсов от своего расположения, но в разметке префикс задан явно, поэтому при переносе на другой адрес сайт нужно пересобрать.

## Локальный просмотр

Сборка рассчитана на размещение в подпапке `/stankin-campus/`, поэтому для локального просмотра её нужно отдавать с тем же префиксом:

```bash
mkdir -p /tmp/site && ln -s "$PWD" /tmp/site/stankin-campus
python3 -m http.server 8000 --directory /tmp/site
```

Откройте http://localhost:8000/stankin-campus/ и войдите с выданными логином и паролем. Адрес `localhost` считается безопасным, поэтому Web Crypto работает и без HTTPS.

## Публикация

Сайт публикуется через GitHub Pages из корня ветки по умолчанию. Чтобы обновить сайт, достаточно закоммитить новую сборку и отправить её в эту ветку.
